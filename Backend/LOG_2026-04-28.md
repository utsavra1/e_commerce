# Development Log - April 28, 2026

## Issues Encountered and Resolved

### 1. Module Resolution Error (ESM Import)
**Time:** Early session
**Issue:** Cannot find module '/Users/utsav/Desktop/Typescript/src/entites/User'
**Error Type:** ts-node ESM module resolution error
**Root Cause:** Missing `.js` file extension on relative import in app.ts
**Solution:** 
- File: `src/app.ts` line 5
- Changed: `import { Role } from './entites/User';`
- To: `import { Role } from './entites/User.js';`
- Reason: ts-node in ESM mode requires file extensions for all relative ES module imports

### 2. Database Query Error - Integer Overflow
**Time:** After fixing import issue
**Issue:** QueryFailedError: value "9090909090" is out of range for type integer
**Error Type:** PostgreSQL type constraint violation
**Root Cause:** Phone number column defined as `type: "int"` instead of `varchar`
**Detail:** PostgreSQL integer max value is 2,147,483,647; phone number 9090909090 exceeds this
**Solution:**
- File: `src/entites/User.ts` lines 21-26
- Changed: Phone column from `type: "int"` to `type: "varchar"`
- Reason: Phone numbers should be stored as strings, not integers
